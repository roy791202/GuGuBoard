第一次使用：設定登入

① 用 GitHub 登入（建議）

  1. 到 GitHub → Settings → Developer settings → OAuth Apps → New OAuth App
  2. Homepage URL 與 Authorization callback URL 都填 http://localhost:8765/
  3. 建立後勾選 Enable Device Flow 並儲存
  4. 把 Client ID 貼到下面（不需要 Client secret）
第一個登入的 GitHub 帳號會成為管理者。
② 或先建立本機管理員帳號（離線備用）
